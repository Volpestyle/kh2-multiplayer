Protocol v15 extends EnemyManifest entries with an optional schema-1 record key.
The key contains all six location/program fields, controller namespace, group,
ordinal/native ID, the complete definition comparison digest, exact header
projection digest and exact 64-byte record digest. Only the eight reviewed keys
are admitted. Raw game data remains outside git. v14 peers fail the existing
protocol handshake; flag mismatch is explicitly refused without point fallback.

On every observation, the adapter uses a complete native census and the existing
double-sampled ordinary record catalog/membership reader. It validates all content,
unique controller/table association, actor/objentry/status/controller/record roots
and a second complete catalog. No historical actor pointer is dereferenced.
The full population must contain exactly three or five living unique records,
with matching host keys and unique host netIds. Pointers, local load serials and
frame counters are local guards, never cross-machine identity.

The lease consumes this first population for the local load and shared host epoch.
Repeated observations require continuous frames, identical local roots/tracked
rows and unchanged host record/netId assignments. Duplicate records, incomplete
content or census, dead/missing bodies, controller/root replacement, conflicting
claims, host respawn with an old friend body, and same-record reuse hold the whole
population. A held lease cannot recover by selecting a nearest/newest body or
replaying an old manifest. Reset requires forward local load and transition
serials plus a forward shared epoch, or a new generation and host connection.
Leaving the reviewed scope cannot erase the consumed-record fence.

There is no same-record incarnation recovery algorithm. Even continuous checked
roots cannot exclude invisible same-address reuse between samples. Consequently
binding-only mode grants correspondence only; the separately reviewed authority
mode has the partial live qualification documented above. It adds no spawn/activation call, memory hook,
native HP writer, widened point radius or family-wide eligibility.
